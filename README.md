# deltarhythm

My spin on a rhythm game! (or, I guess a collection game....) Inspired by Mew Mew's fight in Deltarune chapter 5 and a lot of other rhythm games!

Some assets are *not mine* and belong to their respective owners!

Made for [Terra](terra.hackclub.com)

Arrow keys as controls,
ESC for pause menu!

You can view the live demo [here](https://cheese435.github.io/deltarhythm/rhythm.html).
